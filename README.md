# Open Course Companion

A course app for the UU Osiris Hackathon. You **enter**, **pass on** (doorgeven) and **show** course information. The data is portable by design: everything can leave the app in open formats, so no single system decides who gets your data.

> **Portability test:** if this app disappeared tomorrow, would you still have your data in a form other tools can use? Yes. Your timetable is an `.ics` file, your courses are schema.org JSON-LD, and the whole API is described in OpenAPI.

| Step | What it does | Where |
|---|---|---|
| **Enter** | A form to add or edit a course: code, title, description, ECTS, period, weekly sessions, prerequisites | React form → FastAPI → SQLite |
| **Pass on** | Calendar export (`.ics`), JSON-LD (`schema.org/Course`), share link and QR code, plus JSON-LD import (from a file or a URL) | `/api/courses/{id}.ics`, `/api/courses/{id}.jsonld`, `/api/export/*`, `POST /api/import` |
| **Show** | A dashboard with ECTS progress, a weekly timetable, conflict warnings, suggestions and a prerequisite tree | React pages that read from the API |

## Open standards used
- **iCalendar (RFC 5545):** weekly `RRULE`s with an embedded `VTIMEZONE` (Europe/Amsterdam). Works in Google Calendar, Outlook and Apple Calendar.
- **JSON-LD + schema.org:** `Course`, `CourseInstance`, `Schedule`, `ItemList`. The course page also puts its JSON-LD in `<head>`, so other tools can read it from the page.
- **OpenAPI 3:** generated by FastAPI. Interactive docs at `/docs`, raw spec at `/openapi.json`.
- **QR codes (ISO/IEC 18004)** for share links.
- Plain **SQL** on SQLite, so moving to PostgreSQL later is easy.

## Quick start

You need **Python 3.10+** and **Node.js 20+** (https://nodejs.org).

```powershell
# 1. Backend  ->  http://localhost:8000  (API docs at /docs)
cd backend
python -m venv .venv
.\.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# 2. Frontend (in a second terminal)  ->  http://localhost:5173
cd frontend
npm install
npm run dev
```

The first time it starts, the database (`backend/courses.db`) is filled with sample courses and a sample plan. That plan deliberately includes one timetable clash, so the conflict detection has something to show. You can restore the sample data at any time with **Import / Export → Reset to sample data**.

**Single-process mode:** run `npm run build` in `frontend/`. FastAPI then serves `frontend/dist` itself, so the whole app runs on port 8000.

**Tests:** `cd backend && pip install pytest httpx && python -m pytest`. The tests cover the whole enter → export → import round trip.

## Demo script (about 3 minutes)
1. **Enter:** click **+ Add course**, fill in a course with two weekly sessions and a prerequisite, and save.
2. **Show:** open the course page and set it to *Planned*. The dashboard timetable, ECTS totals and conflicts update. Then open the **Prerequisites** tree.
3. **Pass on (calendar):** click **Add to calendar (.ics)** and open the file in Outlook, Google Calendar or Apple Calendar on stage. All the weekly lectures appear.
4. **Pass on (second app):** start a second copy (for example on another laptop, or with a second backend on another port and its own `OCC_DB`). On **Import / Export**, paste the first copy's JSON-LD URL (`http://<laptop-1>:8000/api/courses/1.jsonld`) or upload the downloaded file. The course appears there, schedule included.
5. **Interoperability:** import `examples/external-course.jsonld`, a course written by "another system" (it uses `@graph`, a list of days in `byDay` and `HH:MM:SS` times). It still imports correctly.
6. Scan the **QR code** with a phone. To make this work, open the app on its network URL (Vite prints it when `npm run dev` starts) instead of `localhost`.

## Suggestions and conflict detection
`GET /api/suggestions?interests=data,web` ranks the courses you haven't planned yet. Every score comes with readable reasons. The rules:
- Courses whose prerequisites you haven't completed or planned are hidden (they are still locked).
- Courses whose prerequisites you have completed score higher.
- Courses that unlock many later courses score higher.
- Courses that match your interest keywords score higher.
- Courses that would clash with your current timetable score lower.

`GET /api/plan` reports two kinds of conflict: **timetable** clashes (same weekday, overlapping times and overlapping periods) and **prerequisite** problems.

The suggester is rule-based on purpose, so it works offline and every result can be explained. To add AI later, replace or extend `planner.suggest()` with an LLM call.

## API overview
| Method | Path | Purpose |
|---|---|---|
| GET / POST | `/api/courses` | List (`?q=` search) / create |
| GET / PUT / DELETE | `/api/courses/{id}` | Read / update / delete |
| PUT | `/api/courses/{id}/status` | `planned` / `in_progress` / `completed` / `null` |
| GET | `/api/courses/{id}.ics` | iCalendar for one course |
| GET | `/api/courses/{id}.jsonld` | schema.org/Course JSON-LD |
| GET | `/api/plan` | Your courses + ECTS totals + conflicts |
| GET | `/api/suggestions` | Ranked next courses with reasons |
| GET | `/api/graph` | Prerequisite graph |
| GET | `/api/export/plan.ics` · `/plan.jsonld` · `/catalog.jsonld` | Bulk exports |
| POST | `/api/import?as_status=planned` | Import JSON-LD (single / list / `@graph` / `ItemList`), matching existing courses by code |
| GET | `/api/qr.svg?data=…` | QR code SVG |

## Project layout
```
backend/
  app/main.py      FastAPI routes
  app/db.py        SQLite schema + plain SQL queries
  app/models.py    Pydantic models + validation
  app/formats.py   iCalendar + JSON-LD export/import  ("doorgeven")
  app/planner.py   prerequisite graph, conflicts, suggestions
  app/seed.py      sample data (fictional course codes)
  tests/           end-to-end API test
frontend/
  src/pages/       Dashboard, Catalog, CourseDetail, CourseForm, Prerequisites, DataPage
  src/components/  Timetable, PrereqGraph, SharePanel, shared UI
examples/
  external-course.jsonld   a course from "another system", for the import demo
```
